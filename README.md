# robloXX

A fresh public foundation for the planet.X Roblox outfit-planning and creator companion.

## What this build does

- Provides a responsive, kid-friendly outfit studio.
- Makes owned, free, preview-only, unavailable, and upload-required states explicit.
- Lets users assemble and rotate an illustrative avatar look.
- Saves demo looks locally on the device.
- Links catalog examples to real Roblox Marketplace searches.
- Explains the acquisition steps and platform boundaries before any live Roblox integration exists.
- Preserves clear seams for Roblox OAuth, authoritative account data, a Roblox companion experience, creator tooling, and future planet.X Store products.

## Truth boundary

This foundation does **not** connect to Roblox, confirm ownership, purchase items, publish assets, or apply an avatar. Those controls are disabled or presented as planned until the official integrations are implemented and verified.

## Local development

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run typecheck
npm run build
```

## Planned phases

1. Public Studio foundation
2. Roblox OAuth and account privacy boundary
3. Real avatar, inventory, ownership, and catalog data
4. Signed handoff to a Roblox companion experience
5. Classic clothing creator
6. 3D asset lab and future planet.X Store preparation

Detailed product planning and verification live in the roboX App Projects system in Notion.
