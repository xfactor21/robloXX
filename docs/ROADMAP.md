# robloXX roadmap

## Phase 0 — public foundation

- Responsive Studio shell
- Illustrative avatar preview
- Truthful ownership states
- Local look saving
- Roblox Marketplace search guidance
- Disabled, clearly labeled integration controls

## Phase 1 — account connection

- Register Roblox OAuth application
- Complete Roblox review
- Implement authorization, refresh, revocation, and disconnect
- Add data minimization and child privacy review gates
- Load real avatar, inventory, ownership, and catalog metadata

## Phase 2 — Roblox companion

- Build the companion experience
- Add short-lived signed outfit handoffs
- Preview selected looks in Roblox
- Use official purchase/claim prompts
- Explicitly save or apply supported owned assets

## Phase 3 — classic clothing

- Template editor
- Safe-area and export validation
- Roblox upload and moderation guidance
- Clear eligibility and fee disclosures

## Phase 4 — 3D asset lab

- Mesh, scale, topology, texture, and cage validation
- Repair guidance
- Export packaging
- Creator eligibility and moderation gates

## Phase 5 — planet.X Store

- Product metadata and downloadable source bundles
- Licenses and entitlements
- Checkout integration only after deliberate activation and verification
- Explicit separation between planet.X purchases and Roblox ownership
